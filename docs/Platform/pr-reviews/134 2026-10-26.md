# Review of PR #134: [Race-free reset of machine credentials](https://github.com/akobr/mono.me/pull/134)

Reviewer: Harry · Review date: 2026-10-26

**Verdict: approve-ready after small fixes.** CI is green, and it isn't stacked on #133.

## Important

- `PutMachine` in `AccessHttp.cs` can now return 400, 404 and 409, but none is declared in the OpenAPI responses, so the generated SDK won't know about them.
- `ResetMachineAccessAsync` replaces the hash first, then patches `/AccessKey` without an ETag. If the second patch fails, the new key works but the caller gets a 5xx and never sees it. Put both fields in one patch.
- `StoreAsync` falls back to an upsert on 404, which contradicts its "a patch never creates a document" comment. It's safe today because it's only used on create, but document it or rename it.

## Nits

- Allow 2–3 retries on 412 instead of one.
- Set `EnableContentResponseOnWrite` explicitly.
- CodeRabbit's point about the `OneTimeSecretDialog.vue` text is valid.

## Good

The compare-and-set on `/HashedSecret` is sound, and the race tests are thorough.
