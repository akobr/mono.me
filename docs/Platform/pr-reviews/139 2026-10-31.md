# Review of PR #139: [Generate the C# SDK with optional parameters and drop the placeholder nulls](https://github.com/akobr/mono.me/pull/139)

Reviewer: Harry · Review date: 2026-10-31

**Verdict: approve-ready once the .NET CI finishes green.** A clean, mechanical change with a well-contained blast radius. The TypeScript SDK check passed; both .NET reference jobs (ubuntu and windows) and CodeRabbit were still running at review time. Nothing is blocking.

## Important

- **Optional request bodies are a footgun.** 28 operations now take `body = null`, e.g. `CreateAccountAsync(AccountCreate body = null, …)` and `UpdateAccessPointAsync(string key, AccessPointUpdate body = null, …)` in `ApiSdk.g.cs`. A caller who leaves the body out compiles fine and sends a JSON `null`, which the API answers with `400`. The README warns about it, but the real fix is marking those request bodies `required` in the OpenAPI document. Track it as a Linear issue.
- **Reordered methods and binary break.** Only `ImportKeyValuesAsync` and `StartViewImportAsync` changed parameter order, with the body moving before the optional query parameters. Both in-repo callers are fixed, and old positional calls fail to compile rather than misbind. Dropping 138 overloads is binary-breaking, though: anything compiled against the old package gets `MissingMethodException`. `Sdk.NSwag` is on `0.10-alpha`, so that's acceptable, but add a release-notes line and consider a minor bump.

## Nits

- `StorytellerImportCommand.cs` around line 99 passes `IsForced ? true : null, IsDryRun ? true : null` positionally into two adjacent `bool?` parameters. Name them `force:` and `dryRun:`.
- `KeyValueReencryptCommand.cs:128`, `SecretTools.cs:38`, `AnnotationTools.cs:654` and `UnderstandingTools.cs:316` pass a bare `true`. Write `reveal: true` and `includeInactive: true`.
- `CatalogReader.cs:88-91` still passes `includeInactive: null, includeDeleted: null, token`. Drop the nulls and pass `cancellationToken: token`.
- Moq setups that omit the token match only `CancellationToken.None`. If a command later passes a real token, they'll quietly return `null`. Use `It.IsAny<CancellationToken>()` in new setups.

## Good

Regenerating without the flag reproduces the old output byte for byte, so the 3.4k-line deletion is purely the overload collapse. MCP tools now pass `cancellationToken:` by name everywhere. The hand-written conditional twins in `ApiSdk.Conditional.cs` keep identical defaults, and the new theory covers all five twins.
