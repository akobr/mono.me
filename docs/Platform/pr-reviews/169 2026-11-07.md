## Important

1. **API still stores the type code as sent.** `StorytellerSetCommand.WithLowerCaseTypeCode` (around lines 235–238) closes the hole for `sform`, and the test proves `EXE.northwind.billing.prod` writes `exe.…`. Any other client can still create `EXE.…` next to `exe.…`. Track a follow-up that canonicalizes in the API write path (and ideally in `AnnotationKey.Parse` / storage), as the PR's Open section already says. Not a reason to hold this PR.

2. **`CreateForKey` duplicates `AnnotationFactory.Create`.** `AnnotationExtensions.CreateForKey` and `AnnotationFactory.Create` both switch on type and fill the same key-derived members. Defaults for a unit now share `Unit.DefaultUnitType` / `DefaultUnitDefinition`, which is good, but a new type or a new required member still needs two edits. Suggested fix when it next hurts: extract a shared builder in `Abstractions.Annotations` (or generate both from one table), so the CLI cannot drift from Normalize again the way this bug did.

3. **Empty `UnitType` / `UnitDefinition` in a file are kept, not defaulted.** `CreateForKey` uses `(source as CoreUnit)?.UnitType ?? CoreUnit.DefaultUnitType`. A file with `"UnitType": ""` (or whitespace) sends the empty string; the server then stores it via `Normalize`, which overwrites the factory defaults from `IUnit`. Suggested fix: treat null/whitespace like missing (`string.IsNullOrWhiteSpace(...) ? Default : value`), and add one theory case next to `Unit_FromAFileWithoutThem_HasTheDefaultsOfACreate`.

## Nits

1. **`WithLowerCaseTypeCode` is string surgery.** It assumes `ToString()` starts with `TypeCode` and rebuilds via `Parse`. Safer and clearer: switch on `key.Type` and call `AnnotationKey.CreateExecution` / `CreateUnit` / … with the name segments (those factories already use the lowercase constants). Same behaviour, no slice.

2. **The non-`JsonException` import failure still uses `WriteImportant`.** After a successful `ToObject` that is not an `Annotation`, lines 126–129 still call `WriteImportant`, which is the path the Open section says throws when stdout is redirected on Windows. The new `JsonException` path correctly uses `WriteErrorLine`. Route that branch the same way (or leave it if it is unreachable in practice).

3. **`Body_LeavesTheRelationArraysToTheServer` skips `unt` and `uxe`.** Low risk if those SDK models omit the arrays when null, but one inline for each would match the completeness of `Body_IsWhatTheApiReads`.

4. **`Answer` in the body tests echoes the raw argument key.** For `EXE.…` the write response stub still says `AnnotationKey: EXE.…` while the request is canonical. Harmless today because assertions read the request; using the lowercased key in `Answer` would avoid a false friend if someone later asserts on the response.

5. **Replace-after-restore remains a sharp edge.** Documented in help, `annotation-lifecycle.md`, and `annotations.md`, and decided with the owner. Worth a one-line warning in the interactive restore prompt itself ("the following write still replaces editable content") so a restore-and-update without `-i` is not a surprise. Optional; not required for merge.

## Good

- Root cause was the right one: mocked `IAnnotationsApiClient` never serialized, so `Required.Always` on `AnnotationKey` and the API's typed body read were invisible. `StorytellerSetBodyTests` fixes that permanently (real client + `ScriptedHttpHandler` + deserialize with `AnnotationsHttp.AnnotationBodyOptions`).
- The four latent bugs (date rewrite, `-c` duplicate crash, bad file as "tool is broken", uppercase type code) were found by running the command after the crash was gone, and each has a focused test. That is how this kind of fix should land.
- Moving `DefaultUnitType` / `DefaultUnitDefinition` onto `Unit` in Abstractions so `sform` and `AnnotationFactory` cannot drift is the correct dependency direction.
- Docs tell the truth about replace semantics, including that restore-then-set still clears what the body omits, and that `sform story restore` is the way to get the old content back.
- Honest verification section: suites claimed green, bodies checked through the real handler once, not run against live Cosmos. Matches what the change needs.
