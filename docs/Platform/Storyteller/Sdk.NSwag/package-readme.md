# Storyteller SDK for .NET

The C# client of the 2S Platform Storyteller API, generated by NSwag. Next to the generated clients it has:

- conditional reads of configurations (`GetConfigurationConditionalAsync`, `GetResolvedConfigurationConditionalAsync`, `GetConfigurationCompositionConditionalAsync`), which send `If-None-Match` and return the status, `ETag`, `Cache-Control` and `X-2S-Secrets-Withheld`, and their formatted twins (`GetConfigurationFormattedConditionalAsync`, `GetResolvedConfigurationFormattedConditionalAsync`), which read the `Content` alone as `flat`, `properties`, `env` or `yaml` text;
- versioned reads and writes of annotations (`GetAnnotationVersionedAsync`, `SetAnnotationVersionedAsync`, `PatchAnnotationVersionedAsync`), which return the `ETag` of the version and send `If-Match` or `If-None-Match`, so a write never overwrites a change it has not seen, and `AnnotationJsonPatch`, which builds a JSON Patch of single members for the merge `PATCH`;
- machine credentials (`StorytellerCredential`): an API key, a certificate, client credentials, workload identity federation (with a token file, or with the ID token of a GitHub Actions job) and a token file, also from the `STORYTELLER_*` variables;
- the shared contract of those variables (`StorytellerVariables`, `StorytellerCredentialVariables`, `StorytellerVariableReader`, `StorytellerUrlRule`): the canonical names, the deprecated `sform` names that are still read, and the rules, which the configuration provider shares;
- an opt-in resilience pipeline (`AddStorytellerResilience`): retries, a circuit breaker and an attempt timeout.

## Install

```powershell
dotnet add package 42.Platform.Storyteller.Sdk.NSwag --prerelease
```

## Usage

```csharp
var credential = StorytellerCredential.FromEnvironment()!
    .Bind(new StorytellerCredentialBinding(new Uri(apiUrl)) { Organization = "acme", Project = "billing" });

services.AddStorytellerSdk(
    () => new SdkConfiguration { BaseUrl = apiUrl, ClientCertificate = credential.ClientCertificate },
    builder => builder.AddStorytellerCredential(credential).AddStorytellerResilience());
```

An application that only reads its configuration uses `42.Platform.Storyteller.Configuration`, which builds on this package.
