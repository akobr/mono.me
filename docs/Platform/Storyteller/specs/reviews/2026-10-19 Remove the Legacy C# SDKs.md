# Remove the Legacy C# SDKs

## Overview

The two unused C# SDKs of the Storyteller API are gone: the RestSharp client in `src/Platform/Sdk` and the Kiota client in `src/Platform/Storyteller/Sdk.Kiota`, with their two entries in `42.mono.slnx`. The eight package versions that only they used are gone from `Directory.Packages.props`. `CLAUDE.md` now names `Sdk.NSwag` as the C# SDK. `Sdk.NSwag`, `sdk.typescript` and everything that uses them are unchanged. The build, the solution, all Platform tests, the pack and both TypeScript projects behave as on `main`, except that the two legacy packages are no longer packed. This review implements [Remove the Legacy C# SDKs](../2026-10-19%20Remove%20the%20Legacy%20C%23%20SDKs.md) in full, in one phase. Linear: [424-63](https://linear.app/424fun/issue/424-63/remove-unused-sdk-code-from-2s-platform).

## What Was Done

### 1. Delete the two projects and their solution entries

- `git rm -r src/Platform/Sdk src/Platform/Storyteller/Sdk.Kiota`: 145 files (55 + 90), as counted in the spec. Neither folder had untracked or ignored files in the worktree, so both folders are gone completely.
- `42.mono.slnx`: the two `<Project>` lines were removed by path. `/Platform/` keeps five projects, and `/Platform/Storyteller/` keeps `Sdk.NSwag` and `sdk.typescript.esproj`. No folder became empty. The file keeps its CRLF line endings.
- `Sdk.NSwag`, `sdk.typescript`, `Async`, the traversal projects and `mrepo.json` are unchanged.
- One commit: `chore(platform): remove the legacy RestSharp and Kiota C# SDKs`. The type follows `ff0b479a chore(platform): remove unused typescript projects`.

### 2. Remove the orphaned package versions

- Before the edit, a search of every `*.csproj`, `*.props`, `*.targets`, `*.proj` and `*.esproj` found no consumer of any of the eight IDs.
- Removed: `JsonSubTypes`, the six `Microsoft.Kiota.*` entries (1.22.1) and `RestSharp`. No other line changed.
- The catalog's order is unchanged. It already had one pair out of order before this change (`NJsonSchema` before `Newtonsoft.Json`); that is out of scope.
- After the build, `Access.AzureAd/test` and `Api.Functions/src` resolve `Microsoft.Graph` 6.7.0, `Microsoft.Graph.Core` 4.0.1 and `Microsoft.Kiota.Abstractions`, `.Authentication.Azure`, `.Http.HttpClientLibrary`, `.Serialization.Form`, `.Json`, `.Multipart` and `.Text`, all at 2.0.0. These are the versions that `Microsoft.Graph.Core` requires. No `Microsoft.Kiota.*` entry was added.
- Commit: `build(dependencies): drop the package versions of the removed C# SDKs`.

### 3. Current documentation

- `CLAUDE.md`: the `Sdk/` row of the Platform table is now `` | `Storyteller/Sdk.NSwag/` | C# SDK (`42.Platform.Storyteller.Sdk.NSwag`), generated by NSwag, used by `sform` | ``, as specified. The other rows were not touched.
- No other current document needed a change. The historical specs and reviews were not edited.
- Commit: `docs(platform): name Sdk.NSwag as the C# SDK in CLAUDE.md`.

### 5. Release note

Neither package ID (`42.Platform.Sdk`, `42.Platform.Storyteller.Sdk`) exists on nuget.org. A copy that an earlier `dotnet pack src` wrote into a checkout's `.artifacts/` stays there until that folder is cleaned. The repository cannot show any other external use of those assemblies. The PR says so.
