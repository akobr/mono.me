# Phase 2 of Unified author and audit actor

## Overview

Phase 2 of [Unified author and audit actor](../2026-10-14%20Unified%20author%20and%20audit%20actor.md) (Linear 424-30) covers section 6 of the spec: the OpenAPI document, both SDKs, `sform` and the admin UI now use the audit stamps that [Phase 1](2026-10-14%20Phase%201%20of%20Unified%20author%20and%20audit%20actor.md) introduced in the API. Every place that printed the raw `account: {sub}` string now names the actor, and links it where the admin UI can.

`dotnet build 42.mono.slnx` succeeds. `Cli.UnitTests` 157 pass. The TypeScript SDK passes typecheck, lint, 99 tests (1 skipped) and the build. The admin UI passes `vue-tsc` (app and e2e), lint, 327 unit tests (2 new), 113 Playwright flows on desktop and mobile (3 skipped, as before), and the 48 visual screenshots in the Playwright Linux container against the committed baselines.

## What Was Done

### 6. Clients

#### OpenAPI and SDKs

- `OpenApiExportTests` exported the document as `open.api.v0.9.7.json` (renamed from 0.9.6 in `Sdk.NSwag/` and `sdk.typescript/`). It differs from 0.9.6 only in the fields of the spec table: `Author`, `CreatedBy`, `DeletedBy` and their times become `$ref`s to `AuditStamp`, and `KeyValueAuditEvent.Actor` a `$ref` to `AuditActor`.
- `Sdk.NSwag/src/ApiSdk.g.cs` is regenerated with the command of its README (updated to 0.9.7). `Sdk.Kiota` is not regenerated.
- The TypeScript SDK is regenerated by `npm run generate` and set to version 0.9.7. Its hand-written code had no author fields.

#### `sform`

- `VersionsConsoleExtensions.WriteVersions` prints `AuditConsoleExtensions.FormatActor(version.Modified?.By)` and the time of the stamp (`—` when missing).
- `KeyValueConsoleExtensions`: the listing, the versions, the recipients ("By") and the audit ("Actor") print the actor with `FormatActor` and the time from the stamp.
- The spec planned an `AuditConsoleExtensions.FormatStamp`; every table keeps separate actor and time columns, so it was not needed and is not added. `kv get` prints JSON, which follows the API.
- The test doubles build `AuditStamp`s and `AuditActor`s.

#### Admin UI

- `AuditActorLink.vue` moves to `components/common/` (its auto-import name stays) and gets a `subtle` prop: muted text instead of the highlighted name, for table cells and version lists. The links and the tooltip are unchanged.
- It replaces the raw author in `VersionTimeline.vue`, the configurations, schemas, templates and key/value pages, `KeyValueDetail.vue` (author and created), `KeyValueVersions.vue` and the key/value audit page. The audit page printed `event.Actor` with an interpolation, which `vue-tsc` does not check, so it would have shown `[object Object]`; a template scan found no other interpolated stamp or actor. Times come from `Modified.At`, `Created.At` (views, recipients). The key/value conflict notice names the author with `actorName`.
- `ConfigurationEditor.vue` puts the saved configuration's `Modified` into the catalog summary instead of `Author` and a local time.
- The mock API serves the new shapes. `mock/audit.ts` gains `accountActor(id)` from the mock directory, so seeded versions, keys, the policy, recipients and audit events name Ada Lovelace, Grace Hopper and Alan Turing with their ids, and writes use the signed-in mock user. The mock stores keep the stamps (`StoredVersion.Modified`, `StoredKeyValue.Created/Deleted`).
- Tests: new `test/unit/components/audit-actor.test.ts` (the version timeline names an account, a machine and `System`; a subtle link goes to the members page and is muted). The e2e test of the audit trail checks that the Reveal row names Grace Hopper and the binding read `machine:mach-billing-sync`. No visual baseline changed: the subtle link renders like the muted text before, and the mock names stayed the same.
