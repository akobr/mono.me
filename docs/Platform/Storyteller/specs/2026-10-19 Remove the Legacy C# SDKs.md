# Remove the Legacy C# SDKs

Linear: [424-63 Remove unused SDK code from 2S Platform](https://linear.app/424fun/issue/424-63/remove-unused-sdk-code-from-2s-platform)

## Problem

The repository still holds two C# SDKs for the Storyteller API that nothing uses and that will not be used again:

- `src/Platform/Sdk/src`: a RestSharp client generated by OpenAPI Generator.
- `src/Platform/Storyteller/Sdk.Kiota`: a client generated by Kiota from `open.api.v0.8.json`.

Since 2026-10-14 the specs call them legacy: "`Api.Web`, `src/Platform/Sdk` and `Sdk.Kiota` are not maintained beyond compiling" ([Active Annotations by Default](2026-10-14%20Active%20Annotations%20by%20Default.md), line 30). They are never regenerated, so they describe an API from version 0.8, while the API is at 0.9.31. They still cost a restore and a build of 145 files on every `dotnet build src`. They keep eight package versions alive in `Directory.Packages.props`. `CLAUDE.md` still names the RestSharp client as "the C# SDK", so a reader or an agent can pick the wrong client.

The maintained clients stay: `Storyteller/Sdk.NSwag` (C#, used by `sform`) and `Storyteller/sdk.typescript` (used by the admin UI).

This spec lives in `docs/Platform/Storyteller/specs/` because both SDKs are clients of the Storyteller API and the history of the SDKs is recorded here. `docs/Platform/Sdk` does not exist.

### The coding plan on the issue

CodeRabbit attached a coding plan to the issue. It was used as a second opinion. This spec agrees with its deletion scope, the eight package entries and the reasons to keep the shared packages and the transitive Kiota abstractions. It differs in two places:

- It removes the `Sdk/` row from `CLAUDE.md`. This spec replaces it with a row for `Storyteller/Sdk.NSwag/`, so the table still names the C# SDK (section 3).
- It asks to run the TypeScript SDK and admin UI pipelines. They do not depend on either project. They run here only as a regression check, because `42.mono.slnx` lists them next to the removed entries (section 4).

## Proposed Changes

### 1. Delete the two projects and their solution entries

- `git rm -r src/Platform/Sdk`. All 55 tracked files are under `src/Platform/Sdk/src`, so the whole folder goes.
- `git rm -r src/Platform/Storyteller/Sdk.Kiota`, including `README.md`, `open.api.v0.8.json` and `src/kiota-lock.json`. `Sdk.NSwag` has its own OpenAPI snapshots; nothing reads Kiota's.
- `42.mono.slnx`: remove the two `<Project>` lines for `src/Platform/Sdk/src/Sdk.csproj` and `src/Platform/Storyteller/Sdk.Kiota/src/Sdk.Kiota.csproj`, matched by path. No folder becomes empty. `Sdk.NSwag` and `sdk.typescript.esproj` stay.
- Not changed: `Sdk.NSwag`, `sdk.typescript`, `Async` (it keeps `netstandard2.1`; it is a reusable library and other consumers remain), the traversal projects and `mrepo.json`.

This is one commit, because a solution entry without its project breaks `dotnet build 42.mono.slnx`.

### 2. Remove the orphaned package versions

- Before each removal, search every `*.csproj`, `*.props` and `*.targets` for the package ID. If a consumer remains, keep the entry.
- Remove from `Directory.Packages.props`: `JsonSubTypes`, `Microsoft.Kiota.Authentication.Azure`, `Microsoft.Kiota.Bundle`, `Microsoft.Kiota.Serialization.Form`, `Microsoft.Kiota.Serialization.Json`, `Microsoft.Kiota.Serialization.Multipart`, `Microsoft.Kiota.Serialization.Text` and `RestSharp`.
- The file stays alphabetical without groups: `JsonPatch.Net`/`LibGit2Sharp`, `Microsoft.IdentityModel.Protocols.OpenIdConnect`/`Microsoft.NET.Test.Sdk` and `QuikGraph.Serialization`/`Semver` become neighbours.
- Do not add a `Microsoft.Kiota.*` entry for `Access.AzureAd`. It gets Kiota 2.0.0 through `Microsoft.Graph`, as before.

### 3. Current documentation

- `CLAUDE.md`, Platform table: replace the `Sdk/` row with
  `` | `Storyteller/Sdk.NSwag/` | C# SDK (`42.Platform.Storyteller.Sdk.NSwag`), generated by NSwag, used by `sform` | ``
  next to the TypeScript SDK row. The other rows of the table, and other stale lines of `CLAUDE.md`, are out of scope.
- No other current document changes. The historical specs and reviews are not edited.

### 4. Validation

- `rg --hidden` (without `.git`, `node_modules`, `bin`, `obj`, `dist`, `.artifacts`) for `Platform/Sdk/`, `Platform\Sdk\`, `Sdk.Kiota`, `Sdk.csproj` (other than `Sdk.NSwag.csproj`), `42.Platform.Sdk`, `_42.Platform.Sdk`, `ApiSdk`, `open.api.v0.8.json`, `RestSharp`, `JsonSubTypes` and `Microsoft.Kiota.` outside `Access.AzureAd`. Matches are allowed only under `docs/**/specs/` and in this spec and its review.

Builds and tests:

- `dotnet restore src`, `dotnet build src` and `dotnet build 42.mono.slnx`.
- `dotnet test` for `src/Platform/Cli/test` (it covers `Sdk.NSwag` in `test/Sdk`) and `src/Platform/Storyteller/Access.AzureAd/test` (the transitive Kiota abstractions).
- `dotnet pack src`: no `42.Platform.Sdk` or `42.Platform.Storyteller.Sdk` package is produced.
- The remaining unit test projects of the Platform, to show that nothing else depended on the removed projects. Tests that need the Cosmos DB emulator or containers run only if that infrastructure is available; the review reports what was skipped.
- `sdk.typescript` (`typecheck`, `lint`, `test`, `build`) and the admin UI (`lint`, `build`, `test`), as a regression check only.

### 5. Release note

The two packages were never on nuget.org. A copy packed locally into `.artifacts/` stays there until it is cleaned. Any other external use of those assemblies cannot be found from the repository; the PR says so.
